# Fronts & Rivals 3.1.0

A fix for fronts resetting after you quit. Your empire carries over.

## Fixes

- Your empire is now saved in Documents\Fronts & Rivals instead of the game's scripts folder, so reinstalling the mod, a mod manager or a game-folder cleanup can never wipe it; an existing save is copied over the first time
- If your save can't be read, the mod tells you and loads the last good backup instead of quietly starting a new empire
- If the empire can't be saved, the mod tells you once and logs why
- A save always reads back: numbers that can't be stored never go into it
- Warns if Fronts & Rivals is installed twice, since two copies would fight over the save

## Download

`FrontsAndRivals-3.1.0.zip` below. Copy the contents of its scripts folder into your GTA V scripts folder, replacing the old files.

Requires Script Hook V, Script Hook V .NET Enhanced and LemonUI (SHVDN3 build). iFruitAddon2 is optional. Single-player only, and free.
